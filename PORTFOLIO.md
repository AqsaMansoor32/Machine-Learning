## Featured portfolio projects

### 1. Customer Churn — Analytics & Predictive Modeling

[**Explore Telco Customer Churn**](https://github.com/AqsaMansoor32/Telco-Customer-Churn-Project)

Studied a telecom churn dataset to understand customer behavior and investigate retention-related patterns. The project includes data cleaning, exploratory visualizations, a Random Forest classifier, preprocessing pipelines, SMOTE, and hyperparameter tuning.

**Questions explored:** How do contracts, tenure, payment methods, and monthly charges relate to churn?

![Churn by contract type](https://raw.githubusercontent.com/AqsaMansoor32/Telco-Customer-Churn-Project/main/outputs/churn_vs_contract.png)

**Skills:** Pandas · Seaborn · Data Cleaning · Classification · scikit-learn

### 2. NYC Airbnb — Price Analysis & Regression

[**Explore Airbnb NYC Analysis**](https://github.com/AqsaMansoor32/AB_NYC_2019-Project)

Analyzed 2019 NYC Airbnb listings and their price distributions. Developed a modeling workflow using a Random Forest regressor, feature preprocessing, and hyperparameter search.

**Questions explored:** How are prices distributed? Which listing characteristics are worth investigating?

![Airbnb price distribution](https://raw.githubusercontent.com/AqsaMansoor32/AB_NYC_2019-Project/main/graphs_output/distribution_price.png)

**Skills:** EDA · Data Visualization · Python · Regression · Model Evaluation

### 3. FaceInsight AI — Computer Vision Application

[**Explore FaceInsight AI**](https://github.com/AqsaMansoor32/faceinsight-ai)

Created a Gradio application that detects faces and displays an estimated age and a binary classification output using an EfficientNetB0-based multi-output model. The project shows the complete inference path, from image preprocessing to interactive results.

**Skills:** TensorFlow/Keras · EfficientNetB0 · OpenCV · Gradio

### 4. Fragrance Concierge — Applied Generative AI

[**Explore Fragrance Concierge**](https://github.com/AqsaMansoor32/fragrance-concierge)

Built a demonstration assistant with three distinct technical roles: **RAG** for catalog-grounded answers, **MCP** for structured inventory tools, and **LoRA** for evaluating voice customization. The project includes documented evaluation and limitations, using a synthetic product catalog.

**Skills:** LangChain · RAG · MCP · LoRA · Python · Model Evaluation
